# Adult-Money-Data-Analysis
# Feature Selection and Data Visualization

## About
This project uses the Adult Income Dataset from the UCI Machine Learning Repository to explore relationships between numerical and categorical features and understand the impact of feature selection on model performance.

## Dataset
- **Name:** Adult Income Dataset
- **Source:** UCI Machine Learning Repository
- **Purpose:** Predict whether a person's annual income is above or below $50K.
- **Features:** Numerical and categorical features.

## Work Performed
1. Loaded and explored the dataset.
2. Handled missing values and duplicate records.
3. Created a correlation matrix and heatmap.
4. Generated pair plots to study numerical relationships.
5. Visualized categorical features.
6. Applied feature selection using ANOVA F-test and Mutual Information.
7. Built Logistic Regression models.
8. Compared model performance using accuracy, precision, recall, and F1-score.

## Tools and Libraries
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Conclusion
This experiment helped identify relationships between dataset features and understand how feature selection can affect the performance of a machine learning model.
